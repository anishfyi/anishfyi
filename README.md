I build backend systems and applied artificial intelligence (AI) at [FableRoom](https://fableroom.com), and I co-founded [Velofy](https://velofy.co), an applied AI and security lab in Delhi. Before that I spent two and a half years on the integrations team at Fyle.

- **AI tooling and harness engineering** · agent harnesses, context engineering, semantic layers and Claude Code plugins
- **Backend** · four years of Django, FastAPI and PostgreSQL
- **Security-minded engineering** · decide first what a system may never do, then enforce it in code: a read-only database role for an agent, a signature check on every inbound webhook
- **Languages** · Python, TypeScript and Rust, plus Swift and C++
